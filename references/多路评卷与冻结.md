# 多路评卷与冻结（W1／W2／W3）

## 1. 三路角色（实质不同，禁止同义改写）

| 路 | 身份 | 专属任务 | 一句话摘要字段 |
|---|---|---|---|
| W1 | 语言错误审计与最小改动 | 逐句列原句／错误点／最小改法／改动词数，区分必改与可不改；核对要点与违规；英语统一按 15 分制语言 9 分档 | 硬错误处数＋改动处数 |
| W2 | 评分维度与升档路径 | 按一档条件逐项定性，设计最短升档路径；拆可迁移亮点句并最小注入；给自评核对表与只背 5 句句库 | 升格后预估档次与分数区间 |
| W3 | 阅卷实操与可复现性 | 独立判分并核对原分数；审查考场 20 分钟可复现性，剔除不可复现项；给 5 分钟自检清单与最小改动优先级 | 独立判分＋最关键三处必改 |

## 2. 五重隔离机制（防"看起来三路其实一路"）

| 机制 | 做法 |
|---|---|
| 上下文隔离 | 三次独立调用／新会话；同一 prompt 内禁止出现三个路身份字样 |
| 文件隔离 | 三份独立 in/out 路径；每路只读自己的 `{{路ID}}_in`，只写自己的 `各路输出文件（运行时生成）` |
| 冻结隔离 | 写盘即冻结；合并前互不可见；冻结后不得因别路结论修改 |
| 摘要隔离 | 每路只回一句话摘要，详细只落盘——即使同屏也无法并列展示多路结论 |
| 校验层 | 合并前跑 `freeze_routes.py`：三文件存在、互不引用对方路名／结论关键词；发现引用或高度趋同 → 判无效，该路换提示顺序重跑 |

**同源输入**：三路必须读同一份"用户已确认的冻结转写文本＋锁定的评分标准"快照，否则 OCR 同源错误会被三路共同继承，形成伪独立。

## 3. 调度层指令（只发一次，不生成任何路结论）

```
本轮启用W1／W2／W3三路独立评卷：
1. 分三次独立调用，每次新上下文，只传"你已确认的冻结转写文本＋锁定评分标准"两份材料；
2. 每次只扮演{{路ID}}，只读{{路ID}}_in，只写各路输出文件（运行时生成），禁止读取或引用其他路；
3. 三路全部落盘并冻结前禁止合并；冻结后任何一路不得因看到别路结论而修改；
4. 每路最终回复只给一句话摘要，详细内容只落盘，不在对话中并列输出多路结论。
```

## 4. 单路模板（复制三次，分别替换变量）

```
你是独立作文评卷路{{路ID}}（{{路身份}}），与其他评卷路完全隔离。
材料：只读{{题目与评分标准}}、{{学生作文转写}}。
禁止：禁止读取其他评卷路文件或结论，禁止本路内同时扮演其他路。
任务：{{路专属任务}}
输出：详细结果写入各路输出文件（运行时生成），回话只给一句话摘要。
```

## 5. 仲裁规则写死（禁用自由裁量）

1. W1 硬错误**一票否决**；
2. W3 判"不可复现"的项**一律剔除**；
3. 分数取三路**交集下沿，就低不就高**，避免虚假承诺；
4. 仲裁者**不得是 W1／W2／W3 任一**；
5. 仲裁输出必须**逐条注明依据哪一路的哪条规则**；
6. 三路关键分歧不平均，列"分歧清单"交用户裁定。

## 6. 冻结脚本用法

```bash
"python3 / python" \
  "本包内嵌资源（见 references/）" \
  --routes W1=<path1>,W2=<path2>,W3=<path3> \
  --out "<routes_frozen.json 绝对路径>"
```

脚本检查：三份文件均存在、逐路计算 SHA-256、检测跨路引用（出现其他路 ID 或"如 W2 所说"类措辞）、检测独特表述高度趋同。退出码 0 = 冻结成功；2 = 发现跨路引用或趋同，需重跑；1 = 输入错误。

## 7. 形式化陷阱判据

- 三路在同一回复段内并列输出 → 视为**未执行**，全部重跑；
- 三路摘要高度雷同（独特主张重合）→ 判**伪独立**，换角色／换顺序重跑；
- 冻结后文件哈希变化 → 判**串味**，该路重跑并重新裁决；
- 仲裁者同时扮演某一路 → 判**仲裁无效**，另起独立调用。
