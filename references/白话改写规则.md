# 白话改写规则（学生版专用）

> 本文件定义作文场景的白话改写口径与专用规则，包含通用术语词表、禁用清单与作文特有的"改稿话术"。

## 1. 三条底线

1. **准确优先**：白话不得牺牲评分口径的准确性。改后句必须真实对应采分点，不许为了好懂说成"随便加两句就行"。
2. **不替学生编经历**：凡涉及具体经历、他人言语、数字地点，原文无据的，改为"这里请写一句你自己的真实感受"，不代写。
3. **初三能懂**：不用专业黑话、长定语从句、emoji；每条≤20 字、动词开头。

## 2. 评分术语 → 学生说法

| 专业术语 | 学生说法 |
|---|---|
| 立意外移／核心词偏移 | 题目里的关键词没回到作文里 |
| 中心突出 | 一眼能看出你想说什么 |
| 材料具体生动 | 有真事、有细节，不是空话 |
| 结构照应 | 开头说的话结尾有回应 |
| 详略得当 | 重要的事多写，不重要的一笔带过 |
| 硬扣清零 | 先把白丢的分捡回来 |
| 定档开关 | 决定老师把你放哪一档的那几处 |
| 贴标签 | 把关键词硬塞进去，看着假 |
| 套作 | 背下来的作文套上去，老师一眼看穿 |
| 可复现 | 合上书你也能在考场做出来 |

## 3. 改动说明句式模板

- "原来这句写的是 {{原句}}，问题是 {{一句话问题}}。"
- "把它换成 {{改句}}，老师一眼就能看到 {{采分点}}。"
- "这一步不用改，因为 {{保留理由}}。"
- "如果这里不改，会 {{具体后果}}。"
- "记住一句话：{{口诀}}。"

## 4. 学生版固定小节顺序

1. 这篇作文考什么
2. 老师为什么没给一类（落档＋差几分，大白话）
3. 我的原文 vs 改后（双栏对照，走岔处红字标【就改这一处】）
4. 记一句口诀
5. 老素材怎么套新题（三层套改表）
6. 变式题（答案在文末"做完再看"）
7. 考场 3–5 条自检

## 5. 双栏对照表写法

复用 `docx_kit.contrast_table(doc, rows)`，rows 为 `(step, mine, right, wrong)`：

- `mine` 列写学生原句的**当时想法**，走岔那行由 `wrong=True` 自动加红字【就岔在这一步】并着红色 `#C00000`；
- `right` 列写改后该怎么想，着正文色；
- 作文场景把表头理解为"我当时这么写"／"改成这么写"，红字标【就改这一处】。

## 6. 口诀示例

| 场景 | 口诀 |
|---|---|
| 核心词三步法 | 题目啥词，标题就啥词；开头点一下，结尾再回家 |
| 三层套改 | 事情不用换，品质调一调，意义重写一遍 |
| 硬扣清零 | 字数先够、错字先清、名字先改 |
| 改后重判 | 三处见关键词，30 秒说出来，才算过了 |
| 反贴标签 | 关键词要化在故事里，不能贴在故事上 |

## 7. 禁用清单

- 禁止"你就是粗心／不认真"式归因；
- 禁止"多读多写就会好"式空话；
- 禁止把答案直接写在变式题旁边（统一放文末"做完再看"）；
- 禁止出现真实姓名／校名／地名；
- 禁止 emoji、网络用语、成人化长句。

## 8. v1.1 全大白话强化（学生版）

学生版从"部分白话"升级为"全大白话"，硬规则如下：

1. **人称**：全程用"我"和"你"，不用"该生／考生／作者"。
2. **术语清零**：下表术语禁止出现在学生版，必须替换为右列说法。

| 禁用术语 | 学生说法 |
|---|---|
| 立意／中心 | 你到底想说啥 |
| 一类文／档位／定档 | 老师会把你放哪一等 |
| 采分点／得分点 | 这句能加分 |
| 结构照应／呼应 | 前面说的话后面有回应 |
| 核心词三步法 | 题目里的词，开头点一下、结尾再回家 |
| 素材三层套改 | 事情不用换，感觉和结尾换一换 |
| 硬扣清零 | 先把白丢的分捡回来 |
| 可复现 | 合上书你也能做出来 |
| 盲估／误差区间 | 没看到卷子，只能大概估一下 |
| 扣题维度无法核验 | 没题目，看不出你写没写对题 |

3. **句长与条数**：每条≤20 字、动词开头；每个小节总条数≤7。
4. **降级标注大白话**：
   - 无题目："这次没给题目，只能看你写得好不好，看不出有没有写对题。"
   - 无分值："没看到卷子分数，下面这个档是大概估的，不一定准。"
   - 文字直录："你发的是文字，没有照片，字好不好看这边看不到。"
5. **三层四要素学生版**：不做四个字段平铺，压成一句动作话，如"事情不动，把'我很累'换成'腰酸得直不起来'，结尾再说一次关键词"。
6. **三思路学生版**：只留"审题一句话"（如"这题就盯住'美'这个字"），写作思路与套改思路不单列，避免一页纸塞不下。
7. **初三复述测试**：交付前抽 3 条，让孩子用自己的话说出来；说不出的词条改写，禁止保留专业黑话。
