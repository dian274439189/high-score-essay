# 数据契约：作文 JSON 字段定义（v1.1）

## 0. 原则

模板与数据分离：**换作文只改 JSON，不改渲染脚本**。渲染脚本内禁止硬编码任何作文内容、汇总表、日期；章节由字段是否存在决定（缺失则跳过）。黄金样例 `assets/样例数据_2026-11-22_九年级语文作文.json` 是回归基准。

v1.1 新增四组字段：降级标注（prompt_available／core_word_source／score_source）、四色标注段（annotated_body）、定稿全文（final_draft）、变式三思路与三层四要素。

## 2. 必填字段校验（v1.1）

| 字段 | 校验规则 |
|---|---|
| `meta.full_score` | 必须为 15／45／50 之一；综能 45 必须在 exam_name 或 score_system 标注"综能／45分制" |
| `recognition_ref.gate` | 必须为 PASS；`mode=image_strict` 时门禁文件必须存在；`mode=text_direct` 时须有 text_direct 门禁记录 |
| `prompt_analysis.core_word_status` | 必须为 confirmed |
| `prompt_analysis.core_word` | 题目与正文两条来源都不能为空；`prompt_available=false` 时 `core_word_source` 必须为"正文反推"且 `reliability_note` 非空 |
| `scoring.final_score` | 0 ≤ 分数 ≤ full_score；档位区间包含该分数；`score_source=系统盲估` 时 `blind_note` 非空且 `estimate_range` 存在 |
| `transcription.annotated_body` | 每段 segments 中 keep＋delete 片段拼接后须与该段 `essay_body.text` 完全一致（change 红字／add 绿字是新增改动内容，不参与还原原文）；每个 segment 的 role 只能 keep／delete／change／add |
| `annotated_body` ↔ `change_list` | 两处 M 编号集合完全相等（闭环）；segments 的 change_id 指向的改动 type 与 role 相符：delete→删、change→换、add→补 |
| `change_list` | 每项必须有 `oral_tip`；type 只能删／换／补 |
| `change_summary.count` | 12–18（白名单外的补写段不计入处数） |
| `change_summary.within_threshold` | 由脚本复算，与手写值不一致即 FAIL |
| `final_draft` | 非空数组；核心词须在首段／中段／尾段三处至少出现（与 L5 三处见核心词一致） |
| `variants` | 每项必须有 `adapt_path` 三层且每层四要素齐全（original／changed／why／how 均非空）、三思路三个数组各≥3 条、`risk` |
| `method_notes` | 四项均非空 |
| `doubts` | 未解决（status=open）数为 0 |

## 3. 输出侧 manifest（脚本生成，不手写）

```jsonc
{
  "schema_version": "1.1",
  "input_ref": "essay_input.json 路径 + 哈希",
  "generated_at": "...",
  "files": {"parent": "output/<日期>/家长版.docx", "student": "output/<日期>/学生版.docx"},
  "checks": {
    "color_audit": "none missing",     // 黑红绿灰四色齐全
    "strike_audit": "present",         // v1.1: 删除线 run 级存在
    "privacy_hits": 0,
    "change_count_match": true,
    "change_id_closed": true,          // v1.1: 编号闭环
    "final_draft_present": true,       // v1.1: 定稿全文渲染
    "variant_count_match": true,
    "dual_consistency": true,
    "gate": "PASS",
    "frozen_unmodified": true
  },
  "status": "PASS | FAIL"
}
```

## 4. 双份 Word 内容契约（v1.1）

| 版本 | 必含章节 |
|---|---|
| 家长版四色诊断报告 | 失分诊断表、四色标注学生原文（黑保留／红改／绿增／灰删除线＋M 编号）、六栏合并表（第几处｜我原来写的｜建议改成｜为什么改｜对应采分点｜不改的后果）、改动量统计、变式三思路＋三层四要素、存疑与能力边界、文末定稿全文；**禁止**出现作文类型／满分／卷面定位轨迹／评分指纹／识别门禁／入口分诊六类元信息 |
| 学生版大白话一页纸 | 我考什么（大白话）、我的原文对改后（红字标【就改这一处】）、记一句口诀、老素材怎么套新题（三层一句话）、考场自检 3–5 条、变式题（答案文末"做完再看"）、降级标注（大白话） |

## 5. 脚本用法

```bash
PY="python3 / python"
SKILL="本技能根目录（.）"

"$PY" "scripts/verify_essay_json.py" --data "<essay_input.json>"
"$PY" "scripts/build_essay_books.py" --data "<essay_input.json>" \
  --out "output/<YYYY-MM-DD>"
```
