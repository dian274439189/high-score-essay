# 识别门禁：把"过关"交给证据和脚本

## 1. 为什么需要脚本裁定

用户明确要求"文字识别完全过关"，而 AI 最容易犯的错就是**自己宣称过关**。本门禁的核心机制：**模型只能产生证据字段，不能产生结论**；`gate` 只能由 `scripts/verify_recognition_gate.py` 根据结构化回执 + 裁切元数据**确定性计算**并写入 门禁结果文件（运行时生成）。任何 PASS 必须有该文件，否则视为失败。

门禁文件含：技能版本、L1 规则文件哈希、时间戳、各指标分子分母、执行模型、抽样复读记录。复跑时比对哈希，不符则重新加载规则并 FAIL。

## 2. 八项量化指标

| 指标 | 公式 | 门槛 |
|---|---|---|
| 层报告覆盖率 | 有 `red_pixel_ratio` 的页数 ÷ 总页数 | = 1.0 |
| 裁切覆盖率 | 有原生裁切证据的手写块 ÷ 手写块总数 | = 1.0 |
| 读图预算合规率 | `read_calls ≤ 5` 的页数 ÷ 总页数 | = 1.0 |
| 易混字符复核率 | 有 3–5x 放大留痕的易混字符 ÷ 易混字符总数 | = 1.0 |
| 存疑闭环率 | `status=resolved` ÷ 存疑总数 | = 1.0 |
| 核心词确认率 | `confirmed` 核心词 ÷ 核心词总数 | = 1.0 |
| 隐私命中数 | 扫描 forbidden 词表命中次数 | = 0 |
| 抽样保真复核 | 随机抽 `max(3, 10%)` 个块重裁复读通过数 ÷ 抽样数 | = 1.0 |

脚本用法：

```bash
"python3 / python" \
  "本包内嵌资源（见 references/）" \
  --envelope "<recognition_envelope.json 绝对路径>" \
  --out "<recognition_gate.json 绝对路径>" \
  --forbidden "张三,某某中学"
```

退出码 0 = PASS；2 = HOLD；3 = RETAKE；1 = 输入错误。

## 3. 三态判定表

| 结论 | 触发条件（全部满足） | 系统动作 |
|---|---|---|
| **PASS** | 八项指标全部达标；`retake.required=false`；C1–C11 全部有证据；脚本退出码 0 | 才允许进入 L1 分诊 |
| **RETAKE（必须重拍）** | 任一页正立判不出／反光倾斜致无法读／缺页／裁切仍切掉笔画／红蓝笔色无法区分 | 停在识别层，输出具体重拍指引（俯拍、光线均匀、字迹完整）；禁止硬读；已有 JSON 不覆盖 |
| **HOLD（停问）** | 存疑闭环率<1.0；核心词确认率<1.0；易混字符无放大证据；抽样复核失败；层报告缺失；C11 追加失败 | 逐条呈现存疑清单，停下来问用户（重拍／补图／口述确认），得到处置后重算门禁 |

## 4. 防自证三道锁

1. **结论外置**：`gate` 只能由脚本写入，SKILL.md 明文规定模型自述"已过关"无效。
2. **抽样复读**：脚本随机抽 `max(3, 10%)` 块，要求重新裁切复读并记录新 `crop_id`；与首次转写不一致 → HOLD。
3. **留痕防篡改**：门禁文件含源文件哈希、时间戳、各指标分子分母；复跑比对，哈希不符 → 重新加载规则并 FAIL。

## 5. 用户如何独立验证

交付时同时给用户一份"识别核验表"（逐条列出 C1–C12 的判定与裁切图↔转写文本左右对照）。用户核对三处即可判断真伪：①易混字符有没有放大图证据；②存疑清单是否逐条有原因；③核心词是否逐词确认。用户回复"确认转写无误"才过 STOP 1。
