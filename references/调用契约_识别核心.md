# 调用契约：使用本包内嵌 L1 识别核心

## 0. 定位与唯一事实来源

本文件只定义**调用契约与门禁不变量**，不复制识别规则全文。识别规则的唯一事实来源为本包内嵌文件：

- `本包内嵌资源（见 references/）` 的 **L1 识别层**、**0.1 三步铁律**、**0.2 禁止事项**、**硬性边界**；
- `本包内嵌资源（见 references/）`；
- `本包内嵌资源（见 references/）` 第一步；
- 误识别模式库：`本包内嵌资源（见 references/）`。

**开局强制**：每次进入 L0，必须先 `Read` 本包 `references/L1_识别核心.md` 并核对版本（规则锁 v2.0.1），未读到 → **停问，禁止进入识别**。上下文压缩后如丢失细节，重新 Read。

**调用范围**：只调用 **L1 识别层**；**禁止调用 L1.5 QVA 与 L2.0 ACV**——作文是主观题，强行调用会触发"语文／英语主观题不得自判"规则，导致链路空转。L1.5 中"D6／P5 回原图复核"的精神，在作文侧转化为 C12 核心词 fidelity 复核。

**为什么不是简单复制规则**：L1 是模型行为规则，不是函数也不是 API；可执行的是 docx_kit.py 等脚本。纯内联会规则漂移，纯外链可能被跳过，故采用"强制加载源规则＋结构化回执＋脚本裁定门禁"的混合契约。

## 1. 输入载荷 recognition_request

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `task_id` | str | 是 | 本次作文任务唯一 ID，用于留痕与回滚 |
| `mode` | enum | 是 | 固定 `recognition_only`（只识别不判题） |
| `gate_profile` | enum | 是 | 固定 `strict`（作文核心词依赖识别，必须最严） |
| `source_images` | array[object] | 是 | `{path, role: prompt\|essay_page\|answer_sheet, page_index, orientation_hint}`；横拍双页 `orientation_hint=unknown` |
| `essay_type` | enum | 是 | `语文作文`／`英语书面表达`，决定评分口径切换 |
| `privacy_tokens` | array[str] | 是 | 需遮蔽的姓名／班级／学号／学校／考号，来自用户或历史对话 |
| `expected_output` | str | 是 | 固定 `recognition_envelope@v1` |
| `source_skill_manifest` | object | 是 | 规则版本 v2.0.1＋L1 文件读取记录与哈希 |

## 2. 回执 recognition_envelope@v1

| 字段 | 内容 |
|---|---|
| `schema_version` / `task_id` | 版本与任务号 |
| `provenance` | `source_skill_version`、L1 源文件读取记录、`read_at` 时间戳、执行模型 |
| `pages[]` | `{page_index, red_pixel_ratio, red_layer_text, layer_note}`；红层为 0 时必须写"（无）"且 note 为精确串 **"AI 独立复核，无红批可依"** |
| `crops[]` | `{crop_id, page, bbox, native_size, upscale_factor, read_call_index}`；每个手写字块必须有原生分辨率裁切证据 |
| `transcription[]` | `{block_id, role: printed_prompt\|student_handwriting\|teacher_red, color, text, flags[]}`；flags 取值见下 |
| `core_word_check` | 作文特有：材料／题目核心词逐词 `{word, source: prompt\|material, status: confirmed\|held, recrop_ref}` |
| `doubts[]` | `{id, type, text, reason, crop_ref, status: open\|resolved}` |
| `retake` | `{required: bool, reason, instructions}` |
| `self_check` | `{color_audit, privacy_hits, read_calls_per_page, ambiguous_recheck_coverage, error_patterns_appended}` |
| `gate` | **只能由 `verify_recognition_gate.py` 计算写入**：`PASS`／`HOLD`／`RETAKE`；模型不得自行填写结论 |

flags 合法取值：`原文如此`／`已划掉`／`识别存疑:原因`／`需重拍`／`公式待核`／`分数待核`／`上下标待核`。禁止出现"空文本且无 flag"的块。

## 3. 十二项识别核验清单（逐条可勾选）

- [ ] **C1 先判层**：每页都有 `red_pixel_ratio`；为 0 的红层写"（无）"且 note 为"AI 独立复核，无红批可依"，未写成"需人工提供答案"。
- [ ] **C2 三色归属**：印刷 `#000000`／学生手写 `#003399`／红批 `#C00000`／标注 `#E67E22`；每块 `color` 合法；红层混学生笔迹标"笔色存疑"。
- [ ] **C3 裁切颗粒度**：整页 Read 会被降采样约 0.2 倍，只能定坐标；每个手写字块有原生分辨率裁切，块约 1100×500 px，禁止整页直接认字。
- [ ] **C4 放大复核**：易混字符（3/C、2/3、5/6、0/O、根号内数字、上下标）`upscale_factor` 在 3–5 倍，有 `read_call_index` 留痕。
- [ ] **C5 读图预算**：每页读图调用 ≤ 5 次；同一区域未反复重读；多栏按栏切留 40px 重叠；两页并排按 x 中点切页。
- [ ] **C6 横拍／双页正立**：横拍双页导出顺时针／逆时针两版缩略图目测判正立，留 `orientation_check` 证据。
- [ ] **C7 转写铁律**：错别字标【原文如此】、涂改标【已划掉】、看不清标【识别存疑：原因】、无上下文补字；无空文本无标记块。
- [ ] **C8 公式与分数**：分数／根号／指数／下标单独标注请用户核对；手写分数向上扩 60–100 px 重裁，不反推补字。
- [ ] **C9 存疑闭环**：`doubts[]` 逐条有原因与 `crop_ref`；`status=open` 必须为 0 才 PASS。
- [ ] **C10 重拍判定**：倾斜／反光／模糊影响识别 → `retake.required=true` 并给俯拍／光线均匀／字迹完整的指引，未硬读。
- [ ] **C11 误识别模式追加**：本轮新误识别模式已追加到本包 `references/error-patterns.md`，同类只记一条并更新次数，有文件变更留痕。
- [ ] **C12 作文核心词复核**：材料／题目核心词逐词确认；任一 `held` → 停问。此为 L1.5 D6／P5"回原图复核"在作文侧的等价实现。

## 4. 识别中的三大硬禁令

1. **禁止编造**：看不清标存疑，绝不脑补文字、细节或分数。
2. **禁止自证**：不得输出"识别已完全过关／识别无误"；只输出"自检结果：PASS／存疑 N 处／需重拍"。
3. **禁止跳层**：识别未 PASS 不得进入分诊、评分与改稿；RETAKE 时禁止硬读。

## 5. 失败三级回退

原生分辨率裁切 → 3–5 倍放大复核 → 用户重拍 → 用户口述／录入文字兜底。走兜底时标 `provenance=user_typed`，明确"非识别过关"，不冒充 PASS；不覆盖已有 JSON。
