## 3. 红队五条铁律终检

交付前逐条打勾：

- [ ] 识别结论由脚本门禁＋用户确认，AI 未自证"完全过关"；
- [ ] 未承诺满分，给出唯一锁定评分基准与条件性区间，写明"不能改书写、不能替你产生真实经历"；
- [ ] 已做入口分诊；未虚构原文事实与感受；无贴标签式核心词插入；
- [ ] 三路真隔离、输入冻结、仲裁规则写死；判伪独立已重跑；
- [ ] 学生版一页纸＋闭卷复现测试通过，考场自检仅 3–5 条，句库标注覆盖不夸大。

## 4. 分层回滚原则

1. **不覆盖已交付版本**：产物写入当日目录下带 `task_id` 的新子目录，全过门禁后才提升为正式文件，旧版保留 `.bak_<timestamp>`。
2. **原子替换**：双份 Word 与 manifest 全部 PASS 后整体发布；中途失败删除本次文件，回退到上一版 manifest 指向的文件。
3. **分层回退**：G1 失败→停在识别层；G4／G5 失败→停在评分／裁决层；G2／G3／G7 失败→只重跑渲染，不重跑识别。
4. **失败留痕**：所有失败写入 失败日志文件（运行时生成）（失败项、时间、输入哈希），禁止静默带过。

## 5. 交付前最后动作

- 遍历两份 Word 的 `run.font.color.rgb`，确认三色真写入；
- 跑隐私扫描，命中 0；
- 确认产物在用户指定的输出目录（默认 `output/`）；
- 调用 present_files 预览家长版（首项）与学生版。
