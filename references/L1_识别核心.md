# L1 识别核心（试卷三色分离提取）

> 定位：专业试卷 AI 识别专家，遵循脱机手写识别技术流程处理一张或多张手写试卷图片。
> 优先级规则：用户发来试卷图片/混合字迹文档并要求识别提取时，**优先激活本技能**，完成三色分离识别后，再把结构化结果交给后续流程（如错题归因、讲评、归档）。

## 与相邻技能的分工边界（防止误触发）

| 技能 | 分工 |
|------|------|
| **本识别核心** | 试卷/混合字迹图片的三层分离识别 + 两份 Word 交付 |

若用户需求就是"把试卷原题、手写答案、红字批改分开提取"，无论哪个学科、是否附带讲评要求，一律走本技能。

## 第一步：前置图像处理

按顺序执行，任何一步失败在详细版中如实记录：

1. **图像预处理**：自动去噪、矫正倾斜、去除污渍阴影；分辨率过低时提示用户重拍（俯拍、光线均匀、字迹完整）。
2. **色彩通道分割**：分离黑色墨迹（学生手写作答）与红色墨迹（老师批改红字），拆分为独立图层分别识别。
3. **印刷原题单独提取**：印刷体与手写文字分区，不混淆。若为纯印刷扫描件（无手写层），跳过手写分支并注明。

## 第二步：识别任务

提取两类内容，做到**原题内容与手写答案按题号一一对应**：

1. 试卷印刷原题文本（印刷体）
2. 学生手写答案文本（黑色字迹，单独提取标注）

**字迹分类规则**：
- 黑色字迹 → 学生手写作答内容，单独提取标注
- 红色字迹 → 老师批改、红字批注、红字答案，单独提取标注
- 铅笔/蓝色笔迹 → 默认视为学生手写，在详细版中注明笔色存疑

## 第三步：高精度校验机制（多分支交叉核验）

1. **三套识别分支并行**：
   - 分支 A：识别印刷原题
   - 分支 B：识别分离后的黑色手写答案
   - 分支 C：识别分离后的红色批改字迹
2. **交叉比对**：同一区域三份结果比对，出现文字不一致、语义不通、连笔模糊无法确定的字，一律标记 `【识别存疑：xxx】`，**禁止自行编造文字**。
3. **语义重打分**：调用语言模型结合初中题目语境修正识别错误，过滤不通顺结果（如数学题中把"至少"误识为"最仁"），最大化手写识别准确率。
4. 查阅 `references/error-patterns.md` 中的历史误识别模式，对同类字词重点复核。

## 输出格式要求（严格遵守）

逐条按试卷题号顺序输出，固定结构，不打乱题号顺序：

```
题号：
  原题（印刷体）及标签：黑色 RGB (0, 0, 0)
  学生手写字答案及标签：深蓝色 RGB (0, 51, 153)
  红字批改 / 红字答案及标签：正红色 RGB (192, 0, 0)
```

**附加规则**：
1. 多张图片输入时，按图片顺序连续识别，标注图片归属（如【图片1】），保持题号连贯。
2. 涂改、划掉的手写文字：保留识别并标注【已划掉】。
3. 不合并题干、不合并不同颜色字迹，印刷、黑手写、红批注三者分区独立。
4. 无对应内容的栏目写"（无）"，不得留空或编造。

## 第四步：交付两份 Word 文档

产出**两份**文档（按 `references/word-output.md` 的模板执行），均保存到 `output/<当日日期>/`：

1. **纯净版**：只含原题（印刷体）/黑字学生手写答案/红字批改三类内容的结构化文本，可直接用于错题归档和二次练习；学生姓名等信息如试卷上有，保留在页首。
2. **详细说明版**：在纯净版内容之外，增加——图片归属标注、三色图层分离说明、每题识别置信度、全部【识别存疑】清单及存疑原因、【已划掉】内容清单、图像质量问题记录。

两份文档用本包自带脚本（scripts/build_essay_books.py）生成：颜色必须真实写入 docx（原题黑 RGB(0,0,0)、手写深蓝 RGB(0,51,153)、红批 RGB(192,0,0)），生成后用 python-docx 自检颜色再交付。

## 持续迭代机制（每次使用后执行）

1. **记录误识别**：每次识别结束，把实际发生的误识别模式（哪个字被认成哪个字、什么笔迹容易出错）追加到 `references/error-patterns.md`，同类错误只记一条并更新出现次数。
2. **记录流程问题**：图像预处理、颜色分离、Word 生成中踩的坑，追加到 `references/error-patterns.md` 的"流程经验"区。
3. **定期收敛**：error-patterns.md 超过 50 条时，合并同类项、删除已通过多次验证不再出错的模式。
4. 用户反馈"某个字识别错了"，当场修正本次输出，并把该模式写入 error-patterns.md。

## 硬性边界

1. **禁止编造**：看不清就是 `【识别存疑】`，绝不脑补文字或答案。
2. **不做内容改写**：原题和学生答案按原文提取，错别字保留并标注【原文如此】（详细版中注明疑似识别问题还是学生原始笔误）。
3. **非试卷图片**：普通照片、截图等非试卷内容，说明边界后转常规识别流程。
