# 最小改动方法（继承用户原有思路 + 门禁修正）

## 1. 核心定义

不换素材、不改结构、不推翻原文、不重写全文，只用**删／换／补**三类微调，把作文推到一类文上沿。默认额度 12–18 处、每处≤20 字；价值不在文采，而在**孩子考场能复现、记得住**。

**白名单例外**（允许突破 20 字）：补写结尾（80–120 字）、字数补足、1 处细节特写（30–50 字）、意义层升华句（≤30 字）。原口径"每处≤20 字"与"补写结尾 80–120 字"直接冲突，故降格为"默认上限＋白名单"。

## 2. 入口分诊（先判能不能改）

| 情形 | 判定 | 处置 |
|---|---|---|
| 核心词偏移但叙事骨架完整 | 适配 | 走最小改动，优先拨定档开关 |
| 结构完整、细节偏空 | 适配 | 走最小改动＋1 处细节特写白名单 |
| 立意根本偏移或结构残缺 | 不适配 | 明说"最小改动不适用"，给重写路径或前置问题清单 |
| 主要失分是书写卷面 | 不适配 | 告知改稿无法解决，给练字与卷面方案 |
| 素材空洞无事例 | 不适配 | 先补真实经历，禁止 AI 编造 |

## 3. 用户原有方法的四条主线（完整继承）

### 3.1 核心词三步法破立意

最大失分点是"核心词被替换"（例：材料关键词"理解劳动的美"被写成"赓续岭南精神"）。做法：①从题目材料原样锁定核心词；②把它请回标题、首段末句、尾段三处；③在正文细节中自然融入承担论证功能。

**加固**：三处必须见核心词；核心词必须"溶解"在句子中，禁止为呼应而硬塞。孤立堆砌判为贴标签，不计有效改动。

### 3.2 老素材套新题型

不背新素材，建转换机制：从题目找触动词 → 搭孩子自己的日常 → 三层套改。

### 3.3 素材三层套改

| 层 | 内容 | 改法 |
|---|---|---|
| 事件层 | 发生了什么 | 基本不动 |
| 品质层 | 体现什么品质 | 按题微调 |
| 意义层 | 对我意味着什么 | 按题重写 |

### 3.4 全周期复盘

六大高频问题清单归类（见家长版附录），不做就文论文的一次性诊断。

## 4. 三层改动优先级（预算分配铁律）

```
第一层｜定档必改（开关级）：标题、首段末句、尾段核心词回嵌 —— 预算优先给这层
第二层｜硬扣清零（送分级）：字数、错别字、标点、化名、卷面
第三层｜档内提分（加分级）：结构照应、细节、金句、升华
```

**前两层未全绿，禁止把预算花在第三层。**

## 5. 改后重判五步门禁

1. 三处见核心词：标题／首段末句／尾段是否都原样含核心词，缺一即未过；
2. 30 秒盲测：未看过原稿者读 30 秒复述中心，与核心词一致才过；
3. 硬扣清零全绿：字数≥600、错别字清零、标点规范、无真实身份、无大面积涂改；
4. 加分信号激活：至少 1 处立意深刻／语言优美／书写优美信号；
5. 重新定档：仍在二档则回炉重做，不是再加描写。

## 6. 八段输出契约（缺一不可）

1. 【失分诊断】维度表＋落档＋差几分＋首要失分点（附原文证据）
2. 【三不改清单】逐句列出完全保留项＋理由
3. 【逐句改动清单】序号｜位置｜原句｜改法｜改后句｜提分点｜是否必改
4. 【关键三处】开头点题／中间转折／结尾升华各一组原句改句
5. 【补写结尾】可直接誊写，标注【新增·需学生确认是否属实】
6. 【可誊写定稿全文】保持原段落顺序与风格
7. 【改动量统计】处数／字数／占比，证明最小改动
8. 【预估得分与风险】条件性区间＋3 条誊写注意＋1 条风险提示

## 7. 三条硬禁令

- **禁止虚构**：不得编造原文不存在的事实、细节、引语、心理活动；补写内容只能是"基于原文已有素材的表达优化／升华句"，涉及具体经历、他人言语、数字地点若无原文依据，改为提示学生"此处请补一句你自己的真实感受"。
- **禁止贴标签**：为呼应而呼应的插入不算有效改动。
- **禁止承诺满分**：统一写"一类文上沿（本卷满分 X 分）"＋条件性区间。
